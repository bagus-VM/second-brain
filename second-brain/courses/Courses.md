# Courses

One folder per course. Each course folder contains:
- Syllabus and schedule
- Grade tracking
- Course-specific notes and references

## How to set up

Tell Professor White:
1. Course name
2. Professor name (optional)
3. Exam date
4. Topics / syllabus (or drop the syllabus PDF into `raw/`)

Professor White will create the course folder and link it to vault pages.
