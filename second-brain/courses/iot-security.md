# IoT Security

**Exam:** 05 August 2026
**Format:** Written, 60–90 minutes (confirmed by Dr. Nikolas via email)

### Exam Question Types
1. **Definitions** — Define core concepts (e.g., IoT, confidentiality). Own words acceptable; must be valid.
2. **Use Case Scenarios** — Given a scenario (smart car/home/agriculture): identify 2 assets, 2 threats, 2 attacks, 2 countermeasures, map to CIA properties, comment on cost/expertise.
3. **Security Solutions** — Explain how a mechanism works (e.g., digital signatures).
