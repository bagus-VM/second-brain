# Source Archive

Copies of every work cited in `../references.bib`, downloaded 2026-10-25.
Files are named by BibTeX key. Paywalled works are recorded as links only;
no paywall was bypassed.

`extraction.csv` holds the paper's per-case extraction table (the data
behind Table III and the case timeline figure) in machine-readable form,
one row per case, with source keys pointing at the files and links below.
