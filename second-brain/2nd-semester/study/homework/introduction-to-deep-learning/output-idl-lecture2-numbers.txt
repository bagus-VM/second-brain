      15      16     singular               basis exhausted

  minimum test error at degree 5 (6 parameters): test MSE 3.281e-03
  interpolation threshold: degree 14, which has 15 parameters for 15 training points
  test MSE at the threshold: 4.547e+00 — 1386 times the minimum

  HONEST RESULT: this demo reproduces the rise toward the interpolation
  threshold and the blow-up at it, and it does NOT reproduce a second
  descent. The reason is structural rather than numerical: a degree-(n-1)
  polynomial with n points is fully determined, so the model class ends
  exactly at the threshold. There is no further degree to grow into, and
  'more parameters than data points' is not reachable in a fixed
  polynomial basis. The double-descent curves in Belkin et al. (2019) and
  Nakkiran et al. (2020) are neural-network curves, where the parameter
  count can pass the number of training points without the function class
  being exhausted. The slide's own caption calls its curves schematic.

10. six points, two distances, two answers
==========================================================================
  k=2 Euclidean  -> [(0.0, 0.0), (0.5, 0.2), (1.0, 1.0)] | [(5.0, 5.0), (5.2, 4.8), (9.0, 1.0)]
  k=2 Manhattan  -> [(0.0, 0.0), (0.5, 0.2), (1.0, 1.0)] | [(5.0, 5.0), (5.2, 4.8), (9.0, 1.0)]
  k=3 Euclidean  -> [(0.0, 0.0)] | [(0.5, 0.2), (1.0, 1.0)] | [(5.0, 5.0), (5.2, 4.8), (9.0, 1.0)]
  k=3 Manhattan  -> [(0.0, 0.0)] | [(0.5, 0.2), (1.0, 1.0)] | [(5.0, 5.0), (5.2, 4.8), (9.0, 1.0)]
  no ground truth exists for which of these is 'right'; the lecture's point on slide 11 is exactly that

  where the distance metric DOES change the answer — nearest neighbour of the origin among two candidates:
    Euclidean  distances [((1.0, 1.0), 1.4142), ((1.5, 0.0), 1.5)] -> nearest (1.0, 1.0)
    Manhattan  distances [((1.5, 0.0), 1.5), ((1.0, 1.0), 2.0)] -> nearest (1.5, 0.0)
    the two metrics disagree about which point is closest, so 'the k nearest neighbours' is only defined once the metric is fixed
