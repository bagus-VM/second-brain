========================================================================
  P1: e1,1 -> e1,2 -> e1,3
  P2: e2,1 -> e2,2
  P3: e3,1 -> e3,2
  m1: e2,1 -> e3,2   (the only message; e3,2 receives it)

  (a) Lamport timestamps
      e1,1   C = 1
      e3,1   C = 1
      e2,1   C = 1
      e1,2   C = 2
      e3,2   C = 2
      e2,2   C = 2
      e1,3   C = 3
      total order via (C_i, i):
        e1,1  <  e2,1  <  e3,1  <  e1,2  <  e2,2  <  e3,2  <  e1,3
      is a linear extension of happens-before: True 

  (b) Vector timestamps
      e1,1   V = (1, 0, 0)
      e3,1   V = (0, 0, 1)
      e2,1   V = (0, 1, 0)
      e1,2   V = (2, 0, 0)
      e3,2   V = (0, 1, 2)
      e2,2   V = (0, 2, 0)
      e1,3   V = (3, 0, 0)
      total order via lexicographic vector comparison:
        e3,1  <  e2,1  <  e3,2  <  e2,2  <  e1,1  <  e1,2  <  e1,3
      is a linear extension of happens-before: True 
      (lexicographic order is a valid linear extension because
       causality gives V(a) <= V(b) componentwise and V(a) != V(b),
       so the first differing component is strictly smaller for a)

  Robustness: 175 linear extensions of happens-before exist.
    distinct Lamport assignments over all of them: 1
    distinct vector assignments over all of them:  1
    -> the timestamps are determined by causality alone, not by
       the order in which concurrent events are listed.
