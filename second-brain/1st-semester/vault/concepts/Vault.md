# The Vault — Compiled Knowledge

This is Professor White's domain. Every page here is **synthesized, not transcribed** — cross-linked, understanding-focused, and kept current.

## Structure

| Subfolder | What lives here |
|-----------|----------------|
| `vault/concepts/` | One page per core concept (e.g., `gradient-descent.md`) |
| `vault/algorithms/` | Algorithm pages with complexity, pseudocode, intuition, pitfalls |
| `vault/topics/` | Topic overviews tying multiple concepts together |
| `vault/connections/` | Insight pages: cross-topic relationships, analogies, contradictions |

## Page format

Every vault page follows a strict template with YAML frontmatter:

```yaml
---
title: "Page Title"
tags: [concept, algorithms, semester-1, course-name]
course: "e.g., Advanced Algorithms"
source_count: 0
status: draft | current | stale
last_updated: YYYY-MM-DD
prerequisites: []
---
```

Then: One-line Summary, Core Intuition, Formal Definition, Key Properties, Worked Example, Common Pitfalls, Connections, Open Questions.
