                Upper Bound
If S ⊆ P then
    x ∈ P is an upper bound of S if [∀y ∈ S | y ≤ x]
    x ∈ P is the least upper bound of S if
       x is an upper bound of S, and
       x ≤ y for all upper bounds y of S
     ⊔ - join, least upper bound, lub, supremum, sup
       ⊔ S is the least upper bound of S
       x ⊔ y is the least upper bound of {x,y}
     x ≤ x ⊔ y and y ≤ x ⊔ y
     if x ≤ z and y ≤ z then x ⊔ y ≤ z

                Lower Bound
If S ⊆ P then
    x ∈ P is a lower bound of S if for ∀y ∈ S. x ≤ y
    x ∈ P is the greatest lower bound of S if
       x is a lower bound of S, and
       y ≤ x for all lower bounds y of S
    ⊓ - meet, greatest lower bound, glb, infimum, inf
       ⊓ S is the greatest lower bound of S
       x ⊓ y is the greatest lower bound of {x,y}
     x ⊓ y ≤ x and x ⊓ y ≤ y
     if z ≤ x and z ≤ y then z ≤ x ⊓ y

    Minimal Fixpoint Algorithm
• So far: naïve algorithm for computing fixpoint
  • Produces a fixpoint
  • Keeps iterating all transb / joinb functions, even if nothing
    changed
• Optimise processing with worklist
  • Set-like datastructure:
    • add element (if not already present)
    • contains test: is element present?
    • pop element: remove and return
  • Tracks what’s left to be done     “MFP” (Minimal Fixed
    Point) Algorithm
Minimal Fixpoint Algorithm (MFP)
 Procedure MFP(⊥, ⊔, ⊑, CFG, trans, is-backward)
 begin
   if is-backward then reverse edges(CFG);
   worklist := edges(CFG);
   foreach n ∊ nodes(CFG) do
     analysis[n] = ⊥;
   done
   while not empty(worklist) do
     ⟨n, n’⟩ := pop(worklist);
     if transn(analysis[n]) ⋢ analysis[n’] then begin
       analysis[n’] := analysis[n’] ⊔ transn(analysis[n])
       foreach n” ∊ successor-nodes(CFG, n’) do
         push(worklist, ⟨n’,n”⟩);
       done
     end
   done
   return analysis;
 end

  Accuracy of Data Flow Analysis
• Ideally, we would like to compute the best solution: the
  meet over all paths (MOP) solution.
  • MOP combines the results from all the possible execution
     paths, but is undecidable
• We can "settle" down to a more "empirically found"
  solution, the Minimum Fixpoint Algorithm (MFP) solution
  • MFP is still sound, but not necessarily as precise as MOP
• If the data flow problem is distributive, then MFP and
  MOP solutions are the same
